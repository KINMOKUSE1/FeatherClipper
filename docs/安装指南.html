Vid2Notes · 第一次使用

装好插件，收下第一段课。

按下面三步操作。无需命令行，连接只配置一次。

① 将扩展装进 Edge

先将压缩包完整解压到长期保留的位置，再打开本指南。

  1. 复制 edge://extensions/ 到 Edge 地址栏并打开。
  2. 打开“开发人员模式”，点击“加载解压缩的扩展”。
  3. 选择安装包里的 course-clipper 文件夹。可将下方目录复制到文件选择窗口的地址栏，回车后点击“选择文件夹”。
安装包中的 course-clipper 文件夹（里面有 manifest.json）。

安装后保留这个文件夹。在 Edge 的扩展菜单中，将“Vid2Notes”显示在工具栏。

② 连接 Obsidian

  1. 打开笔记库，在设置 → 第三方插件 → 浏览中搜索 Local REST API，安装并启用。也可以在 Obsidian 中查看插件。
  2. 打开它的设置，启用 HTTP 服务（Enable HTTP server），复制 API Key。默认地址是 http://127.0.0.1:27123；如果修改了端口，请使用实际地址。
  3. 点击浏览器里的“Vid2Notes”图标 → 配置 Obsidian，填入地址和 Key，然后测试连接 → 保存设置。

使用 HTTPS 时，按 Local REST API 文档配置证书与地址。

③ 导入你的第一段视频

  1. 保持 Obsidian 打开，在 Edge 打开一段有字幕的 B站或 YouTube 视频。
  2. 点击“Vid2Notes”图标，确认字幕预览，点击“导入”。
  3. 回到 Obsidian，在 Clippings/Bilibili 或 Clippings/YouTube 查看刚导入的字幕。

需要导入 B站整门课？点击“整门课程”，勾选分 P 后导入。完成后打开“整理笔记”，填写偏好并复制任务指令，把材料交给你常用的 AI。

更新版本：关闭扩展页面，用新版文件替换原安装目录中的文件，在扩展管理页点击“重新加载”。
更多设置与常见问题见安装包中的“使用说明.md”。
