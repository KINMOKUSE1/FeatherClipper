# 从课程字幕到学习笔记

先用插件把字幕导入 Obsidian，再交给你常用的 AI 整理。原始字幕便于回看，章节笔记用于理解、练习和复习。

## 三步开始

1. **选素材。** 在课程工作台勾选要学习的视频并导入。课程目录中会生成 `课程导入清单.md` 和 `原始字幕/`。
2. **交给 AI。** 本指南和 `NOTE_TEMPLATE.md` 是给 AI 的规则与格式；课程清单和对应字幕是本次素材。能访问笔记库的本地 AI 可按路径读取；网页聊天 AI 需要上传或粘贴这些文件。已有个人学习规则时一起提供。`PROMPTS.md` 是给你参考的示例，不必上传。
3. **整理并核对。** 复制插件中的“任务指令”，或使用 `PROMPTS.md` 的例子。每次处理一章或明确选中的 P，回看关键例题和疑点，再添加自己的理解。

## 我的偏好

按需要修改这些默认值：

- 学习目标：理解课程、完成练习与复习。
- 输出目录：`Note/课程笔记/<课程名>/`。
- 笔记作者：填写自己的署名；留空时成品省略作者字段。
- 整理范围：每章一篇；指定 P 或文件时按指定范围整理。
- 命名：整章用 `课程缩写-章节序号-主题.md`；小节用 `课程缩写-章节序号-小节序号-主题.md`；单 P 用 `课程缩写-P序号-主题.md`。
- 语言：简体中文，专业术语首次出现保留英文原名。
- 外部资料：允许补充解释并注明来源；联网可用时检索字幕提到但未完整收录的真题。

本次明确要求和个人学习规则优先于这些默认值。

## 整理方法

### 确认覆盖范围

读取课程清单与实际文件，以清单确认章节归属。记录可用素材、未导入、无字幕和文件缺失；以实际分 P 清单核对数量。保留标题中的“拓展”“例题”“大纲已删”等标注。单文件任务可直接从文件开始。

### 把讲解变成知识结构

按小节组织概念、定义、适用条件、公式、推导和易混淆点。合并重复讲解，保留不同实例。长章先分小节整理，再统一术语并合成一篇完整笔记。

教师例题放在对应知识点附近，按“条件与数据 → 过程 → 结论与理由”展开。保留具体参数、代码、算法输入、中间状态、拓扑、权值和表格条目。教师强调的原话可用引用块；补充示例与改写解释单独标明。

### 保留回看的入口

关键例题、引文和疑点附具体 P 与来源时间链接。字幕缺少的板书、图表、公式或题干列为“需回看视频”，写清位置和缺失内容。重要术语、数值和符号有识别歧义时列为待核实。

课程内容、整理者解释和外部资料分别标注。补入真题时核对年份、科目、题号、题干及答案出处，附可靠链接；尚未找到原题时保留已有线索。来源有冲突时说明差异。

### 形成可复习的笔记

按 `NOTE_TEMPLATE.md` 输出要点、术语表、详细笔记、自测题与答案、来源和“我的补充”。按知识覆盖需要安排自测题，标明为生成练习。图表放在对应小节：比较用表格，流程与结构用 Mermaid，真实时长和并行关系用比例时间线。

## 保存与继续学习

- 交付前核对小节覆盖、例题数据与推导、术语、来源、公式和图表。已有批注与人工修改保留；后续补充合并到对应小节，难以合并时另存修订稿。
- `draft` 表示整理中，`partial` 表示本次范围仍有影响完整性的缺失，`complete` 表示已核对完成。单 P 的状态对应这个 P。
- 在课程目录的 `整理进度.md` 记录范围、成品路径、已用 CID／文件、缺失项和状态。单文件任务也可直接在成品中记录。
- 原始字幕留在采集目录，课程导入清单由插件维护。需要归档时整体移动课程目录并更新引用，补抓前检查归档位置。
- 成品使用实际来源、日期和标签；多词标签用连字符。表格内 LaTeX 的竖线用 `\mid`、`\lvert` 和 `\rvert` 表达。
- 交付时说明成品位置、处理范围和待核实项；聊天工具可直接输出供保存的 Markdown。

## 经常使用：安装学习技能

点击插件中的“下载技能包”，按包内说明安装 `course-notes`。它包含上述整理方法、默认模板，以及翻译、增量补充和复习的处理步骤。以后指定课程和范围即可调用。

包内还提供 `obsidian-mermaid` 流程绘图技能，以及可选的 `obsidian-css-timeline` 比例时间线技能。已有同名技能时继续使用即可；时间线需要 Python 和 Obsidian CSS 代码片段。普通聊天工具可直接使用这三份 Markdown 文档。
