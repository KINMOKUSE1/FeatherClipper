# Task-specific guidance

The task instructions determine the task type; later explicit user instructions may change it. Read the general workflow in workflow.md first. The following sections add guidance for each task

## Study notes

Read the selected subtitles or files and produce study notes using personal configuration. A course index is not required; use workflow.md to confirm scope and grouping and record actual known sources

When foreign-language materials are to become Chinese study notes, reorganize them by topic and retain original terms where needed. Source language alone does not change granularity or trigger a translation task

## Translate subtitles

Provide original text and target-language translation by semantic paragraph, keeping time references, important terms, and specific data. Retain teacher examples. Deliver long materials in segments and state actual coverage for this round. Use the configured module rules when a glossary or summary is needed

Follow this task's translation requirements, retain alignment between original and translated text, and identify missing board work, formulas, or problem statements

## Continue notes

Read the user's existing notes or progress first. Confirm completed scope, unfinished portions of the current note, terminology, and naming, then continue the remaining content within the specified scope. Obtain existing notes or progress first if unavailable

Use confirmed groups and task scope. Finish the current note's remaining explanations, examples, and derivations first. Local tasks can continue to the next note within scope; web tasks continue the note for the current video or material file

When progress is enabled, update it from actual completed work and save or return outputs following the environment-specific delivery in workflow.md

## Supplement existing notes

Compare new materials, original notes, and items to verify to locate the corresponding output. Add content under the relevant topics. For grouped notes, add section 2.3 material to the 2.3 note and Lecture 02's new 02.5 or Part to the Lecture 02 note. For one note per video, supplement that video's note

Preserve manual annotations and record additions and resolved issues. Present source conflicts side by side with differences and citations. Retain original content beyond the new materials even if its subtitles are not provided again

Read the original notes before merging; obtain them first if unavailable. Web tasks supplement content for the current source, retain original content, and revise and deliver in rounds following workflow.md

## Review and questions

Organize explanations, knowledge outlines, or exercises around the current question or exam/project goal. Use examples from provided course materials and existing notes to explain conditions and reasons, labeling supplementary examples clearly

Deliver an answer by default and merge it into notes only on explicit request. When sources lack an answer, distinguish existing evidence, the note writer's derivation, and unresolved points rather than inventing teacher statements

## Missing exam questions

When materials mention an incomplete exam question and external sources are allowed, an AI with search capability uses the year, subject, question number, and known conditions as clues. Prefer official papers or verifiable sources. Check the question, options, answer source, and correspondence with the teacher's explanation

If the complete question cannot be found or searching is unavailable, retain confirmed content and label it “Original question not fully included”. Label independently derived answers as the note writer's solutions. Follow personal configuration for external additions; do not restore disabled sections because of them
