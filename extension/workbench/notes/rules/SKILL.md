# 课程笔记整理

用户本次明确要求优先于个人配置，个人配置优先于通用流程中的默认处理方法。采用所选栏目和属性，素材作为内容来源

## 开始前读取

1. 读取 [整理流程](references/workflow.md)，完整执行材料确认、知识组织、解释过程及交付核对
2. 读取 [个人偏好](references/preferences.md)，确定语言、粒度、目录、命名、回看与进度设置
3. 读取 [内容模块](references/modules.md) 和 [笔记属性](references/properties.md)，采用启用的栏目、顺序、写法及填写规则
4. 写作前读取 [Obsidian 与 Markdown 写作](references/markdown.md)，处理加粗、代码围栏、表格公式、YAML 属性和链接

## 按任务读取

任务类型由本次指令指定。读取 [任务说明](references/tasks.md) 中对应部分：整理笔记、翻译字幕、继续整理、补充已有笔记、复习答疑；素材提到不完整真题且允许检索时读取“缺失真题”

课程内容适合绘图或用户要求创建、修改图表时，读取 [Mermaid 图解](references/mermaid.md)，按内容选型、核对来源并检查图表

本地与网页环境的素材确认、写作及交付方式见整理流程，按本次任务报告实际处理结果
