# 课程笔记整理流程

根据 preferences.md、modules.md 和 properties.md 确定本次写作配置，按以下流程处理实际素材

## 1. 确认材料与范围

本地任务根据本次指定范围及可用的课程导入清单确定成品分组，读取当前分组的字幕及必要的前置内容；单文件任务直接读取该文件。网页任务每次处理一个视频或一个上传的素材文件，已有笔记和进度作为参考；本轮材料以实际上传的内容为准

本次任务明确列出的分组优先于课程清单，清单优先于原始字幕中的章号或标题推断。每个视频一篇时分别整理所选视频；按组整理时采用已确认的分组

按组整理且尚未确认分组时，根据标题识别：

- Lecture／Lec／L数字标记的课程以讲次为基本单元：Lecture 02.1–02.4 归入 2，L1、L4 分别归入 1、4；同一讲次的 Part 和同号 LIVE 合成一篇，分段内容放在内部小标题中
- 普通数字章节保留完整两级编号：2.2 的多个 P 合成一篇，2.3 另成一篇，不合并为第 2 章。2.10 等编号作为分组字符串保留
- 讲次识别依据 Lecture／Lec 或独立的 L数字标记，课程语言和平台不作为讲次依据
- 0 表示未分章，不是共同章节。未分章素材按用户指定范围处理；需要合篇且范围不明确时先确认

部分选中时按所选视频或文件记录本篇实际覆盖范围。区分文件可用、未导入、无字幕、读取失败和内容缺失。小节编号跳号不等于漏抓，保留“拓展”“例题”等原标注

## 2. 梳理知识结构

在每个成品分组内按概念和知识点重组口语字幕。统一术语，合并重复讲解，保留适用条件、不同实例和条件差异

每次集中完成并核对一篇笔记，再进入下一篇。长篇可以分轮提取和写作，保持当前篇的知识结构、例题和推导完整，记录术语、已完成范围及待处理位置；发现缺失时回查原素材

本地环境支持且允许使用 subagent 时，可将独立的成品分组分别交给子 agent，每个接收当前分组的材料和适用配置，并交付完整笔记、来源及未完成项。主 agent 统一检查术语与跨篇联系，保留各篇完整内容；前后依赖较强的分组按顺序处理。没有此能力时按顺序逐篇完成

## 3. 保留解释过程

定义、公式、推导与教师例题一同整理。例题保留题干条件、具体数据、代码或算法输入、关键中间状态、解法和结论；贯穿讲解的拓扑、权值、表格条目按来源保留。解释结果为什么成立，不用只有结论的概括代替推导

教师特别强调且可确认的短句用引用块呈现，改写和补充示例另行标明。字幕缺少的图、板书、公式、参数与题干注明位置，不推测为教师原文

## 4. 补全必要背景

区分课程内容、整理者解释和外部资料。按个人配置决定是否补充外部资料，补充时注明实际出处；自行推导的解答标为整理者解答。字幕提到不完整的真题时，按 [任务说明](tasks.md) 中“缺失真题”处理

未确认的题干、公式或板书列为待核实，写清位置及影响。按所选回看方式提供可确认的视频标识和时间，避免同一来源的重复链接

## 5. 形成学习笔记

采用已选栏目、写法、属性和命名；用户提供个人模板时按本次要求使用。写作时读取 [Obsidian 与 Markdown 写作](markdown.md)，检查加粗边界、代码围栏、表格公式、属性类型及链接

新术语首次出现保留必要的原名。启用自测模块时按模块写法生成题目，将生成练习与教师原题、检索得到的真题区分

## 6. 按内容绘图

对比和映射可用表格，流程、结构、状态和消息交互可用 Mermaid。图形能改善理解时读取 [Mermaid 图解](mermaid.md)，将图放在对应知识点附近；文字或表格足够清楚时直接采用

## 7. 核对并交付

对照实际素材逐项检查小节覆盖、例题条件与步骤、推导、术语、公式及来源。篇幅由素材和所选写法决定。保留人工批注；增量补充写入对应知识点，来源冲突时并列写清差异与出处，难以合并时另存修订稿

本地 agent 在允许的目录内保存成品，原始素材保留在采集目录，课程导入清单由导入器维护。仅在启用整理进度时更新整理进度.md，记录实际处理范围、成品路径、已用素材及缺失项

网页 AI 用 Markdown 或可下载 .md 文件交付本轮实际完成的内容，由用户保存到建议位置。分轮交付时说明已完成范围、停止位置及剩余内容；修订长篇笔记时保留原有内容，全部完成后返回完整修订版。启用进度时一并交付建议的进度文档

完成状态对应本次实际处理范围，报告成品位置或建议文件名及待核实项。复习答疑默认交付回答；用户明确要求更新笔记时才修改成品
