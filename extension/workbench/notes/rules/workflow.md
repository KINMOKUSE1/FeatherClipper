# 课程笔记整理流程

先读取 preferences.md、modules.md 和 properties.md。本次明确要求优先于这些个人配置；个人配置决定目录、命名、粒度、栏目、属性和回看方式。以下流程保留整理方法，不补回未选择的栏目或属性

## 1. 确认材料与范围

读取课程导入清单及对应字幕；单文件任务直接读取该文件。网页任务只读取用户实际上传的文件和内容，本机路径不能代替上传的素材

本次任务明确列出的分组优先于课程清单，清单优先于原始字幕中的旧章号或标题推断。用户选择每个视频一篇时，分别整理所选视频；选择按组整理时，采用已确认的分组，不再根据旧标题重新分组

没有确认的分组、需要根据标题识别时：

- Lecture／Lec／L数字标记的课程以讲次为基本单元：Lecture 02.1–02.4 归入 2，L1、L4 分别归入 1、4；同一讲次的 Part 和同号 LIVE 合成一篇，分段内容放在内部小标题中
- 普通数字章节保留完整两级编号：2.2 的多个 P 合成一篇，2.3 另成一篇，不合并为第 2 章。2.10 等编号作为分组字符串保留
- 讲次识别依赖 Lecture／Lec 或独立的 L数字标记，不凭英文语言或平台猜测讲次。旧清单仍按分段编号时，先重新识别并确认分组，再整理成品
- 0 表示未分章，不是共同章节。未分章素材按用户指定范围处理；需要合篇且范围不明确时先确认

部分选中时只处理所选视频或文件，注明本篇实际覆盖范围。区分文件可用、未导入、无字幕、读取失败和内容缺失，不把未提供的素材视为已读。小节编号跳号不等于漏抓，保留“拓展”“例题”等原标注

## 2. 梳理知识结构

在每个成品分组内按概念和知识点重组口语字幕。单组内容较长时可分批提取，再合成为该组笔记；不要因上下文长度把同一组随意拆成多篇。统一术语，合并重复讲解，保留适用条件、不同实例和条件差异

## 3. 保留解释过程

定义、公式、推导与教师例题一同整理。例题保留题干条件、具体数据、代码或算法输入、关键中间状态、解法和结论；贯穿讲解的拓扑、权值、表格条目按来源保留。解释结果为什么成立，不用只有结论的概括代替推导

教师特别强调且可确认的短句用引用块呈现，改写和补充示例另行标明。字幕缺少的图、板书、公式、参数与题干注明位置，不推测为教师原文

## 4. 补全必要背景

区分课程内容、整理者解释和外部资料。用户允许补充且当前 AI 具有检索能力时，检索字幕提到但不完整的真题，核对年份、科目、题号、题干、选项及答案出处，优先使用官方试卷或可核查来源

查不到完整原题时保留已确认内容，标明原题未完整收录；自行推导的答案标为整理者解答。用户禁止外部资料时仅使用所提供素材；没有检索能力时注明未核实，不声称已经检索

未确认的题干、公式或板书列为待核实，写清位置及影响。按所选回看方式提供可确认的视频标识和时间，避免同一来源的重复链接

## 5. 形成学习笔记

使用 modules.md 中启用的栏目、顺序及写法，使用 properties.md 中启用的属性及填写规则，按照 preferences.md 的语言、粒度、目录和命名组织成品。用户提供个人模板时，在本次明确要求及个人配置的范围内采用；不额外搜索旧工作流文档或套用其他内置模板

新术语首次出现保留必要的原名。启用自测模块时按该模块写法生成题目，将生成练习与教师原题、检索得到的真题区分；不因关闭自测模块而自动补回练习栏目

## 6. 按内容绘图

对比和映射可用表格，流程、结构、状态和消息交互可用 Mermaid。需要绘图时读取 [Mermaid 图解](mermaid.md)，按内容选型，把图放在对应知识点附近，核对数据、关系、单位和显示效果；文字或表格足够清楚时不强行绘图

需要精确表达时间区间时保留起止值、单位和时长，可用表格列出；普通时间线的视觉间距不作为时长比例。本地与网页环境共用本文的绘图规则，网页环境输出包含 Mermaid 源码或表格的 Markdown，没有渲染能力时说明未完成渲染检查

多词 Obsidian 标签用连字符连接。中文图解使用表格、Mermaid 或图片；表格中的 LaTeX 竖线使用 \mid、\lvert 和 \rvert

## 7. 核对并交付

对照实际素材检查小节覆盖、例题完整性、术语、公式和来源。保留人工批注；增量补充写入对应知识点，来源冲突时并列写清差异与出处，难以合并时另存修订稿

本地 agent 在允许的目录内保存成品，原始素材保留在采集目录，课程导入清单由导入器维护。仅在启用整理进度时更新整理进度.md，记录实际处理范围、成品路径、已用素材及缺失项

网页 AI 输出完整 Markdown 内容，支持文件交付时可返回 .md 文件，说明建议文件名供用户保存。补充已有笔记时输出完整修订内容；启用进度时一并输出建议的进度文档，不声称已读写本机文件或更新 Obsidian

完成状态只对应本次范围：单 P 完成不代表整门课程完成。报告实际覆盖范围、成品位置或建议文件名及待核实项。复习答疑默认交付回答；用户明确要求更新笔记时才修改成品
