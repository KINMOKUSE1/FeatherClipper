# 共用字体

字体声明统一维护在上一层的 `fonts.css`。

- **Geist**：课程内容中的英文和数字
- **Noto Serif SC**：课程内容与字幕使用的衬线字体
- **HarmonyOS Sans**：“整理笔记”“本地转写”“连接配置”三个设置页面，提供 400、500、700 字重
- 侧栏使用系统字体栈

Geist 与 Noto Serif SC 的许可见本目录的 `OFL-Geist.txt`、`OFL-NotoSerifSC.txt`。
