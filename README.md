# Bilibili Course Clipper（暂定名）

面向大学生自学场景，将 B站课程中的可用字幕（包括平台 AI 字幕）批量导入 Obsidian，并通过可编辑的 Markdown 工作流，配合用户选择的 AI 整理章节笔记。

基于 [haixiong1997/Bilibili-Obsidian-Clipper](https://github.com/haixiong1997/Bilibili-Obsidian-Clipper) 二次开发，保留原项目 MIT 许可证与署名。原项目已支持字幕获取和 Obsidian 导入；本项目围绕整门课程的批量采集、章节组织和后续整理流程进行改造。

## 项目状态

当前代码是已完成批量导入功能的个人版原型，尚未完成产品精简。上游 AI 侧边栏、模型配置、阅读模式等仍在代码中，不能将下方目标描述为已经实现。

已实现：同一 BV 的全分 P 目录读取、章节预分组与修改、选择导入、原始字幕和课程清单写入、已有文件跳过、失败重试及停止。原始字幕按 CID 保存，课程清单按章组织。

已验证：14 项逻辑测试、使用真实课程目录和模拟导入结果的浏览器页面测试。尚未完成用户 Edge 登录环境下的真实字幕写入验证。

## 已对齐的产品方向

完整流程：课程视频 → 提取可用字幕 → 批量导入 Obsidian → 按章组织素材 → 用户依据 Markdown 规则调用自己的 AI → 形成并完善课程笔记。

- 插件负责课程素材采集、章节组织、来源追踪、导入状态与缺失说明。
- 原始素材按 P 保留，课程清单按章组织，最终学习笔记默认每个大章一份。
- AI 生成笔记由用户自行完成；插件不配置模型、不调用 AI、不提供聊天侧边栏。
- 工作流使用可编辑的通用 Markdown 文档，不绑定某个模型或 Agent，不包含个人作者名、私人配置或 API Key。
- 主要操作集中在一个页面，设置一次可达，统一颜色、间距、按钮和状态样式。
- 首版支持 B站同一 BV 的多分 P，通过 Obsidian Local REST API 写入。多个 BV 的合集、其他平台和无字幕音频转录暂不纳入。

## 本地开发与使用

- `tests/`：自动化测试。

- [LICENSE](./LICENSE)：原项目许可证。

```text
node --test tests/course.test.cjs
```
