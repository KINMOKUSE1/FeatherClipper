# Bilibili Course Clipper · 课程入库

面向大学生自学的 B站课程素材导入器：把同一 BV 的多分 P 字幕批量送进 Obsidian，按章组织清单，再用自己的 AI 和 Markdown 规则整理学习笔记。

**插件负责导入素材，用户决定如何整理。** 原始字幕按 P 保留，最终学习笔记默认每个大章一篇。插件不调用模型，不提供聊天侧边栏。

基于 [haixiong1997/Bilibili-Obsidian-Clipper](https://github.com/haixiong1997/Bilibili-Obsidian-Clipper) 的概念与 MIT 代码二次开发，保留原项目许可证和署名。上游已有字幕获取（包括平台提供的 AI 字幕）及 Obsidian 导入能力；本项目的改造重点是**整课批量导入、章节组织、清晰的功能边界和可编辑的整理工作流**。

## 当前功能

- 点击图标打开快捷窗口：自动识别当前视频、预览字幕并导入单个 P；收起窗口后后台继续导入，结果会保留。
- 需要批量处理时进入课程工作台，读取同一 BV 的全部分 P，按标题编号预分章，也可手动调整。
- 选择当前 P、指定章节或整门课程，预览字幕后导入。
- 保留完整可用字幕、时间戳、视频链接、BV 与 CID；优先选择中文字幕。
- 已有素材自动跳过；显示无字幕和失败原因，支持停止、重试及重新打开后继续。
- 自动更新按章组织的课程清单，保留每个 P 的状态。
- 快捷窗口内可配置连接；课程工作台集中提供分章、多选和笔记生成说明。
- 提供学习指南、笔记模板和整理指令，可保存到 Obsidian；可下载课程整理与绘图技能包。

已移除上游 AI 模型配置、对话与侧边栏、阅读模式、播放器改造、评论采集及 SRT/TXT 下载。版本为 `1.2.0`。

## 开始使用

1. 在 Obsidian 启用 [Local REST API](https://github.com/coddingtonbear/obsidian-local-rest-api)。
2. 在 Edge 的扩展管理页开启开发人员模式，加载本仓库的 `extension/` 文件夹。
3. 在 B站视频页点击扩展图标，打开快捷窗口并自动预览当前 P。
4. 点击“配置 Obsidian”，填写本机服务地址与 Key，测试并保存。
5. 点击“导入 P…”保存当前视频；需要多选与分章时，点击“批量导入整门课”。

完整步骤及升级方法见 [使用说明](./使用说明.md)。

## 从字幕到章节笔记

默认素材目录为 `Clippings/Bilibili/`。每门课程包含 `原始字幕/CID-编号.md` 和 `课程导入清单.md`。点击“开始整理笔记”：

1. **保存学习文档**：将指南、模板和示例指令写入素材根目录的 `学习工作流/`，已有文件保留。
2. **复制整理指令**：带入当前课程、勾选的 P 和素材路径；未勾选时使用当前 P，未读取课程时提供填写模板。
3. **下载技能包**：安装 `course-notes`，以后直接指定课程和范围；包内另有 Mermaid 绘图和可选的比例时间线技能。

- [学习指南](./extension/workflow/WORKFLOW.md)：开始步骤、个人偏好与整理方法。
- [笔记模板](./extension/workflow/NOTE_TEMPLATE.md)：知识点、实例、自测题与来源结构。
- [更多指令](./extension/workflow/PROMPTS.md)：继续学习、翻译、补齐素材和复习。
- [技能包说明](./learning-kit/README.md)：内容、安装位置和调用示例。

本地 AI 工具可读取文档、清单和字幕；聊天工具可接收上传或粘贴的内容。整理时保留教师例题、推导与来源，把字幕缺少的板书、公式和题干列为回看项。个人学习规则与模板可随时修改。

## 范围

首版支持一个 BV 下的单 P 或多分 P，不包含跨 BV 合集、其他平台或无字幕音频转录。需要在使用扩展的浏览器中登录 B站，并保持 Obsidian 打开。快捷窗口可在导入期间收起；批量导入需保持课程工作台打开。字幕是否可用取决于 B站返回的数据。

仅连接本机 `127.0.0.1` 或 `localhost` 的 Local REST API。扩展不会请求模型服务，Key 保存在浏览器扩展的本地设置中。

## 开发

扩展可以直接加载 `extension/`。使用支持内置测试运行器的 Node.js：

```sh
node --test tests/*.test.cjs
```

学习技能源文件在 `learning-kit/`。修改技能或工作流文档后运行 `python scripts/build_learning_kit.py`，更新随扩展提供的下载包。打包仅使用 Python 标准库。

测试覆盖章节归属、CID 去重、来源链接、缺失与失败处理、避免覆盖已有文件、连接设置和工作流导入。浏览器交互测试使用真实课程目录与模拟写入；安装后可先导入一个 P，核对真实字幕及 Obsidian 连接。
