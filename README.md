# Course Cove

![Course Cove 图标](./extension/icons/icon48.png)

**Video subtitles to Obsidian**

把 B站和 YouTube 的视频字幕收进 Obsidian，再按自己的方式学习。

面向大学生和自学者的 Edge 扩展。B站课程可按分 P 批量导入，YouTube 视频和播放列表也可预览、选择并导入。插件保存原始字幕、时间戳与来源链接；学习笔记由你选择的 AI 按自己的规则整理。

[安装当前开发版](#安装与首次使用) · [详细说明](./使用说明.md) · [下载旧版 v1.2.1](https://github.com/KINMOKUSE1/bilibili-course-clipper/releases/download/v1.2.1/course-clipper-edge.zip)

## 主要功能

- **视频与课程导入**：在 B站或 YouTube 视频页预览并导入字幕；B站课程可批量选择同一 BV 下的分 P，YouTube 可选择播放列表中的视频。
- **字幕与回看链接**：按视频实际提供的语言选择字幕轨，区分人工字幕与自动字幕；保存完整字幕、时间戳和视频链接。
- **课程素材管理**：按标题预分章，也可手动调整；自动生成课程清单，跳过已有字幕，支持停止和重试。
- **自己的笔记工作流**：提供学习规则、模板和可选技能包，用你选择的 AI 整理章节笔记。
- **可选本地转写**：无字幕时可手动尝试用本机模型转写视频音轨；整课模式只处理已勾选且无字幕的分 P。

导入字幕无需配置 AI 模型或模型 API Key；首次连接 Obsidian 后即可使用。

## 安装与首次使用

### 1. 装好浏览器扩展

1. 当前 v1.3.5 开发版：下载本仓库源码并解压，使用其中的 `extension/` 文件夹；或在本地使用 [已生成的 ZIP](./downloads/course-clipper-edge.zip)，**完整解压**到一个长期保留的位置。GitHub [v1.2.1 发布包](https://github.com/KINMOKUSE1/bilibili-course-clipper/releases/tag/v1.2.1)仍是旧版，尚不包含 YouTube 功能。
2. 打开 `edge://extensions/`，开启“开发人员模式”，点击“加载解压缩的扩展”。ZIP 内附有 `安装指南.html`，可以双击查看图文步骤。
3. 若使用 ZIP，选择解压后的 **`course-clipper` 文件夹**；若使用仓库源码，选择 **`extension` 文件夹**。然后将“Course Cove”固定到工具栏。

安装包里已准备好扩展，**无需 Git、Node.js 或命令行**。安装后保留解压目录。

### 2. 连接 Obsidian（只需一次）

1. 打开笔记库，在 **设置 → 第三方插件 → 浏览** 中搜索 **Local REST API**，安装并启用。
2. 打开它的设置，启用 **HTTP 服务（Enable HTTP server）**，复制 API Key。默认本机地址为 `http://127.0.0.1:27123`；改过端口时使用实际地址。
3. 点击“Course Cove”图标 → **配置 Obsidian**，粘贴地址和 Key，点击 **测试连接 → 保存设置**。

需要 HTTPS 或连接遇到问题时，查看[详细说明](./使用说明.md#连接-obsidian)及 [Local REST API 文档](https://github.com/coddingtonbear/obsidian-local-rest-api)。

### 3. 导入第一段视频

在 Edge 打开一段 B站或 YouTube 视频，点击扩展图标。预览区默认 **自动（推荐）**，下拉菜单列出当前视频实际提供的字幕轨（例如 English、English 自动生成、简体中文）；选择后预览和导入使用同一条轨道。YouTube 自动翻译语言不作为已有字幕轨列出。确认内容后点击 **“导入”**，回到 Obsidian 就能找到原始字幕。YouTube 字幕从视频页读取；请保持该视频可正常播放。

整课工作台保留 **批量语言偏好**（自动／中文／英文）；预览某个视频时，还可以单独选择它的真实字幕轨，此选择仅对该视频生效，并优先于批量偏好。指定的语言或字幕轨不可用时会提示失败，不会静默换成其他语言。

YouTube 播放列表导入会逐个读取视频页，并尽量复用插件创建的标签页。批量导入会自动激活读取页；部分页面仍需保持浏览器可见，最小化后可能无法加载文稿。获取方式见下方[技术路线](#技术路线)。

字幕会合并成便于阅读的段落，预览与导入规则一致：YouTube 优先按句末标点、停顿分段，B站按约 30 秒一段合并；较长间隔会另起一段。保留全部文字，每段显示一个可回看原视频的起始时间戳。新规则只影响预览和新导入的文件，已有笔记不改写。

想收集整门课？点击 **“批量导入整门课”**，勾选视频、核对章节，点击 **“导入 … 个视频”** 即可。

章节按标题中的编号识别，数字编号最多保留两级：`2.2.4_4` → `2.2`、`2.3.1_1` → `2.3`；`Lecture 19, Part 1–4` 同属 `19`，不会把视频序号或课程编号当成章号。也支持 `第二章第三节` → `2.3`、`第十八讲` → `18`；无明确编号时为 `0`（未分章）。章节号可手动填写为 `2`、`2.3` 等；已保存的分组继续保留，点击 **“重新识别章节”** 可按新规则替换当前列表的分组，不改写已有字幕文件。

### 可选：为无字幕视频安装本地转写

基础扩展直接读取现成字幕，不需要下载模型。遇到无字幕的视频，建议先寻找内容相同、带字幕的版本；找不到时可点击 **“本地转写并导入”**，工作台会提供独立安装向导。也可从仓库的 [可选安装包](./downloads/course-cove-asr-installer.zip) 下载：解压并运行 `install.cmd`，选择有足够空间的磁盘和目录；完成后运行安装目录里的 `启动本地转写.cmd`，把向导显示的连接码填进工作台。此后转写仍需你逐次点击，不会自动启动。

YouTube 接入、播放列表与本地转写更新已加入本仓库的 v1.3.5 源码及本地 ZIP；上方链接的 v1.2.1 GitHub 发布包尚未包含这些改动。现在体验新版，请在 Edge 加载本仓库的 `extension/` 文件夹；发布包会在下一次发布时更新。

转写模型约 461 MiB，Python 和依赖还会占用额外空间。安装器检测到 NVIDIA 显卡时可选择额外安装 GPU 运行库；已有安装可运行新安装包里的 `enable-gpu.cmd`，选择原来的安装目录。GPU 首次转写前会试跑，无法运行时提示原因并改用 CPU。它只作为无字幕场景的扩展功能，已存在的字幕仍走普通导入路径。批量转写按钮仅处理**已勾选且显示“无字幕”**的分 P，已有文件会跳过。转写结果标明来源，学习时请结合视频核对错词、公式和板书。[详细步骤与限制](./使用说明.md#可选的本地转写)

## 从字幕到章节笔记

默认将 B站素材保存到 `Clippings/Bilibili/`，YouTube 素材保存到 `Clippings/YouTube/`。每个视频或课程目录有一份清单和一个原始字幕文件夹：

- **课程导入清单**：查看分 P、章节归属和导入状态。
- **原始字幕**：B站采用“分 P 名称 [CID-编号].md”，YouTube 采用“视频标题 [YT-视频ID].md”；笔记保留完整字幕与时间链接。
- **章节笔记**：交给你的 AI 按规则整理，默认按清单中的完整章节编号每组一篇，例如 `2.2`、`2.3` 分别成篇，同组多个 P 合并；也可以只整理指定 P。主要内容标题旁通常放一个视频回看入口；后半讲回扣、跨视频补充等可放在对应子标题旁，正文减少重复时间链接。论文、网页等非视频引用不受影响。

导入后，在工作台点击 **“开始整理笔记”**：

1. 首次点击 **“保存学习文档”**，在 Obsidian 的 `学习工作流/WORKFLOW.md` 填写学习目标和笔记目录。
2. 勾选要整理的分组中已导入的分 P，点击 **“复制任务指令”**。指令列出课程清单和字幕文件的路径，**不包含文件正文**；未勾选分 P 时不会复制。
3. 本地 AI 若能读取笔记库，粘贴指令即可让它按路径读取；网页聊天 AI 还需上传 `WORKFLOW.md`、`NOTE_TEMPLATE.md`、课程导入清单和所选分组对应的原始字幕。`PROMPTS.md` 只是给你参考的指令示例。
4. 核对教师例题、推导与来源，再加入自己的理解。字幕没收录的板书、公式和题干会作为回看项处理。

常用本地 AI 工具的用户可以 **下载技能包**：`course-notes` 负责整理、翻译、补充与复习；`obsidian-mermaid` 绘制流程和结构图；`obsidian-css-timeline` 用于比例时间线。安装方法见[技能包说明](./learning-kit/README.md)。普通聊天工具直接使用 Markdown 文档即可。

## 技术路线

### Bilibili：通过平台字幕接口读取

根据 BV 与每个分 P 的 CID 请求 B站网页自身使用的播放器接口（`/x/player/wbi/v2`、`/x/player/v2`），获取字幕轨和字幕文件地址，再下载有效正文。第一个入口返回空字幕列表或空正文时，继续尝试其他可用轨道与入口；登录和访问限制会单独提示。这条路径不需要逐个激活视频页、等待文稿面板渲染。这里使用的是平台网页接口，并非面向第三方承诺稳定的公开 API。

### YouTube：已有文稿 → 两路字幕文件 → 打开文稿面板

1. **先读已有文稿**：查找页面中实际包含有效时间戳与正文的面板，优先使用展开的面板；不以某个固定 panel ID 是否存在判断成功。
2. **并行获取字幕文件**：一路使用当前页面播放器数据中的字幕地址，另一路请求播放器接口取得字幕地址；先取得有效正文的一路返回，取消另一条路径。
3. **文稿面板兜底**：尝试展开视频简介、点击转写入口，等待有效正文，再按用户所选字幕轨读取。

文稿识别以内容为主，保留旧固定选择器作为兼容兜底，并兼容新旧片段及正文节点。即使隐藏的旧面板仍存在且为空，也能优先找到另一面板中的实际字幕。重新预览会重新读取；只有紧接着导入同一视频、同一字幕选择时，才复用一次成功预览。

“传统／新版文稿结构”描述页面布局；“后台可读／需要前台激活”描述加载行为，两者不能直接画等号。已有正文可直接读取，但部分页面需要激活标签页才能加载或更新文稿，当前还不能保证最小化浏览器后继续完成整课导入。

### 写入与整理

两平台的有效字幕都通过 Obsidian Local REST API 写入本机笔记库，生成原始字幕与课程导入清单。原始字幕按阅读段落保留回看时间；成品笔记由用户选择的 AI 按 Markdown 规则生成。可选本地转写走独立组件，由用户手动触发。

## 与参考项目的关系与改进

**相较于 Bilibili Obsidian Clipper，重点是从单个视频采集扩展到整门课。** [上游项目](https://github.com/haixiong1997/Bilibili-Obsidian-Clipper) 已有 B站字幕获取（包括平台 AI 字幕）、预览和 Obsidian 导入，也提供阅读视图、字幕下载和 AI 侧边栏。Course Cove 保留采集与入库核心，移除内置 AI 对话等界面，把整理交给用户自己的工具；新增整课多选、章节分组、导入清单、跳过已有文件与重试，并扩展 YouTube 播放列表和可选本地转写。

**相较于 Obsidian Web Clipper，重点是课程组织与连续导入。** [Web Clipper](https://github.com/obsidianmd/obsidian-clipper) 面向通用网页剪藏，提供高亮、模板等功能，使用 Defuddle 提取内容。Course Cove 参考其 YouTube 提取思路，围绕分 P／播放列表增加批量处理、逐视频字幕轨选择、完整章节编号分组，以及“学习规则＋笔记模板＋任务指令”的整理流程。

在文稿兼容上，我们将原先依赖固定外层容器的定位改为“有效片段优先、旧选择器兜底”，处理无固定 ID 的新面板及空旧面板共存的情况；语言控件跟随实际选中的面板。对照的是 [Defuddle YouTube 提取器](https://github.com/kepano/defuddle/blob/main/src/extractors/youtube.ts) 于 2026-09-27 查阅的源码。这里说明具体适配与产品侧重，不代表所有视频上的速度或成功率都优于参考项目。

## 常见问题

**所有视频都能导入吗？**

支持 B站同一 BV 下的单 P、多分 P，以及 YouTube 单条视频和播放列表。打开列表中带 `v=` 与 `list=` 的视频链接，工作台会列出可读取的列表视频；列表外的视频不会混入。优先读取平台已有字幕；没有可用字幕时，可以额外安装本地转写组件并尝试转写可读取的音轨。

**可以关闭窗口吗？**

快捷窗口可以收起，导入任务会继续执行；批量导入时保持课程工作台和 Obsidian 打开。YouTube 的部分文稿依赖前台页面加载，请保持读取页和浏览器可见；收起扩展弹窗不等于可以最小化浏览器。

**重复导入会覆盖笔记吗？**

同一课程目录内按视频 CID 识别，分 P 后来改名或文件仍采用旧的 `CID-编号.md` 名称，也会跳过已有原始字幕并保持清单链接有效。插件不会自动重命名旧文件，以免破坏你已有的链接和批注。学习文档也会保留已有版本。目录调整与去重细节见[文件组织说明](./使用说明.md#文件组织与重复导入)。

**如何更新？**

关闭扩展页面，用新版文件替换原安装目录中的文件，在扩展管理页点击“重新加载”。详细步骤见[使用说明](./使用说明.md#安装或升级)。

## 开发与打包

只调整弹窗样式时，可以在 VS Code 内使用示例数据预览。在仓库根目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory extension
```

在 VS Code 命令面板选择 `Simple Browser: Show`，打开 `http://127.0.0.1:8000/preview.html`。顶部可切换单 P、系列课程、无字幕、加载与保存等状态，也可展开字幕。修改 `extension/popup.html` 或 `extension/popup.css` 后，点击“刷新预览”。预览复用正式弹窗文件，所有扩展接口使用内存中的示例数据，不请求视频平台或写入 Obsidian；真实读取与保存仍在浏览器扩展中验证。

直接加载 `extension/` 开发。运行测试：

```sh
node --test tests/*.test.cjs
```

修改扩展或学习文档后，重新生成下载包：

```sh
python scripts/build_install_package.py
```

脚本会更新学习技能包、可选转写安装包，再生成 `downloads/course-clipper-edge.zip`；打包仅使用 Python 标准库。转写组件需要另行下载 Python 运行环境和模型。
