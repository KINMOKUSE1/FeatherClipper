# Obsidian Mermaid 图解

1. 读取目标段落及其来源，列出图要表达的节点、关系、条件和数据。
2. 根据[图表选型](references/diagram-types.md)选择表达方式。概念对比用表格，流程用流程图，消息交互用时序图；复杂关系拆成总览和局部图。
3. 生成图表并放在对应小节旁。保留来源中的数值、方向、分支和标签；补充示意单独标明。
4. 检查节点标识、括号、引号、箭头和代码围栏。在可用渲染环境中预览，检查文字遮挡、关系方向与阅读顺序；交付时说明尚未完成的检查。

## 写法

- 节点使用唯一的字母、数字或下划线 ID；中文放在显示文本中，例如 `step1["收到 ACK"]`。
- 子图用短 ID 和显示标题，例如 `subgraph phase1["拥塞避免"]`。
- 复杂节点文本和边标签用英文双引号包围；文本中的双引号可写为 `#quot;`。
- 流程采用 `flowchart TD` 或 `flowchart LR`；决策节点用 `{}`，起止节点用 `([])`。
- 节点首字符避免 Markdown 编号 `1.`，可写为 `①`。解释性长句放在图外，保持节点简短。
- 时序图根据消息含义选择箭头样式，在标签中写清请求、返回或事件；状态图标明转换条件。
- 颜色和分组用于区分实际类别；多个主题分图表达。

用户只要图时，给出一句说明和 Mermaid 代码块；用户要求写入笔记时，保留周围正文和批注。中文内容使用原生图表表达。
